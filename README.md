# CONNECTA Frontend — Batch 1

Initial mobile-first frontend for CONNECTA.

Included:
- Landing page
- Login page
- Registration page
- App-style dashboard
- Green/white CONNECTA design system
- Responsive mobile/desktop layout
- Demo localStorage authentication flow

Important:
The login/register flow is currently a frontend demo only. Firebase Authentication and the backend will be connected in the next stage.

Open `index.html` in a browser to preview the project.
